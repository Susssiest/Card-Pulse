# Card Pulse Project BUILD JOURNAL


## Printed Test Version

I printed a test version. The case has a few tolerances that need to be adjusted, and I realized that there were a few non manifold randomly extruding parts of my mesh. Fixed mesh and tolerances in blender by cutting off part that doesnt need to be fixed and applying mirror modifier to delete the messed up side, and then connecting back to good mesh. Reprinting now, hopefully everything works.
