# Custom-TCG-Slab-Display
A little TCG display that can hold a card in a slab with WS2812B on its sides and a screen on its base.

# Journal

## Session 1

Started working on the 3d printed frame. Main idea is to have a stand that can plug into a wall outlet and display the led and card price. Going to have leds on the sides, and a oled screen to display the price. Using blender, experiencing the usual problems, non manifold vertices, overlapping vertices, etc. Using ws2812b leds for the bars. I am probably going to use a standard 35pt toploader, but I might make one for psa card slabs. Imported reference card to make it more realistic.

3 hours worked.

## Session 2

I kind of think the frame looks ugly, so I'm restarting. This time I'm thinking of actually having it mobile, and more like a portable case than a frame that sits on your wall. I will be adding a 3.7 v lithium battery, and a 5v booster, as well as a button and rotary enocoder. I feel like it would be cool to make it so you can scroll through different stats on the oled, and maybe even have a wifi choosing menu and led control menu. This complicates my design a lot, so I;m expecting my project to take a little more time than originally expected.
